# 3tsv Suite — 极简轻量的 VST3 混音套装

一套不到 3MB、解压即用、全自研的 VST3 插件套装。没有花里胡哨的界面，只有像螺丝刀一样趁手的混音工具。

> **本仓库仅发布编译好的二进制文件，不提供源代码。**

## 包含插件

| 插件 | 说明 |
| --- | --- |
| **3tsvRack** | 机架宿主，可自选插件目录，支持加载第三方 VST3 |
| **3tsvEQ** | 4 段均衡，带实时频谱 |
| **3tsvComp** | 压缩器，混合探测 + 软拐点 + 自动补偿 |
| **3tsvReverb** | 16 线 FDN 现代算法混响 |
| **3tsvConvolute** | 卷积混响，加载自己的 WAV 脉冲响应 |
| **3tsvTube** | 胆机饱和器，双三极管电路模型 |
| **3tsvLimiter** | 带过采样的砖墙限制器 |

## 🎧 核心特性

- **绿色免安装**：无 DLL 依赖，解压双击即用，不写注册表。
- **现代 DSP 架构**：抛弃十几年前的老旧算法，底层纯净，没有数字毛刺。
- **低延迟**：0 采样混响干声延迟，延迟如实上报宿主，极低 CPU 占用。
- **全部验证过**：每个插件都有离线自测 + VST3 validator 通过记录。

## 🚀 快速上手

1. 在右侧 **Releases** 下载最新的 `.zip` 压缩包并解压。

## 📦 各插件简介

### 3tsvRack — 机架宿主

独立的 VST3 机架程序（Windows x64），把插件像链条一样串起来用。可自选插件目录，加载任何第三方 64 位 VST3；插件编辑器直接内嵌在机架窗口里，支持 Show GUI 一键全部显示/关闭。链路配置一键 Save/Load（`.vst3rack` 格式），勾选 Auto Save 后退出自动保存、下次启动自动恢复。总旁通、上移下移、卸载都有按钮；音频走 waveOut，无需 ASIO 驱动。

### 3tsvEQ — 四段图形均衡

四个频段画在同一条真实频响曲线上，直接拖节点调整，所见即所得（画曲线和算系数是同一份代码）。每段可独立选 Bell / Low Shelf / High Shelf / High Pass / Low Pass；零延迟 IIR，参数 20ms 平滑无拉链噪声；内置不占音频线程的实时频谱分析器和立体声电平表；五套预设（VOCAL / BASS / AIR / TELE / FLAT），拖回预设值自动认出预设名。滚轮调 Q、双击回默认、数值框直接输入。

### 3tsvComp — 压缩器

前馈拓扑 + dB 域增益计算 + 混合探测器（峰值与准 RMS 取大），低频不抽风、瞬态不漏过。二次曲线软拐点，人声总线平滑、鼓组硬朗可调。阈值 -60~0 dB、比率 1:1~20:1、Attack 0.1~100 ms、Release 10~1000 ms（对数刻度）。Makeup 带 Auto 自动补偿；侧链高通（Off/100/150 Hz）防止底鼓压扁总线；Mix 干湿比做并行压缩。主界面是显眼的 GR 增益衰减表，压得越狠颜色越暖。

### 3tsvReverb — 16 线 FDN 算法混响

干声 0 采样延迟的纯算法混响。16 条互质素数延迟线构成反馈延迟网络，反馈矩阵用快速沃尔什-哈达玛变换实现，能量严格守恒绝不自激；阻尼与低频搁架按线长独立缩放，长短线的衰减率一致；BASS 低频倍率由每条线的反馈增益反推，数学上不可能啸叫。9 个推子（SIZE / DECAY / BASS / DAMP / WIDTH / PRE / MIX / LOCUT / MOD），内置 SMALL 到 AMBIENT 六个预设，尾音宽而密，长衰减下无金属味。

### 3tsvConvolute — 卷积混响

加载你自己的 WAV 脉冲响应（支持单声道/立体声/四声道真立体声，PCM 16/24/32 与 float），重现真实空间的声学特质。两级分块卷积引擎：前 170ms 用 256 采样高分辨率块，尾音用 2048 采样长块，比均匀分块省约 6.5 倍运算，最长支持 6 秒 IR 而整体只报 256 采样延迟。预延迟、阻尼、谐振可调；载入 IR 自动裁掉尾部静音、限长淡出、峰值归一并重采样到工程采样率；界面直接显示 IR 波形。

### 3tsvTube — 胆机饱和器

把信号推过一支 12AX7 双三极管，而不是套一条失真曲线。偶次谐波由随包络移动的工作点偏置产生，推得再大也不消失；低频先饱和带来厚度，电源下陷（SAG）给出真实的吸气感/阻塞感。只留 4 个推子（DRIVE / WARMTH / MIX / OUT），级数、变压器、直流阻断、自动补偿全部后台自动；响度自动补偿让 A/B 不被音量骗。4 倍过采样 + ADAA 抗混叠，界面带动态辉光的胆管图和 CORE 拐点电平表，CLEAN 到 CRUNCH 六个预设。

### 3tsvLimiter — 砖墙限制器

真正的 brickwall：峰值检测用单调队列滑窗取精确最大值，配合前瞻把增益提前压到位，不过冲。可选 1x/2x/4x 半带滤波器过采样，把增益调制的失真整体推到 Nyquist 之外；前瞻 0~20 ms、释放 5~1000 ms，另有双段 AutoREL（50ms 快咬合 + 参数尾音）。立体声链接在 dB 域插值，深压限声像不晃；CEIL 上限与 THR 合成同一增益，无二次削波。干湿比 MIX 可做并行压限，延迟如实上报宿主自动对齐。
